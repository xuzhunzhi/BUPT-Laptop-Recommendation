# 基础知识篇

目前主流的Windows笔记本搭载的都是X86/AMD64（AMD64又称X64）架构处理器，MacBook搭载的是苹果基于ARM架构魔改的M/A系列处理器。Windows阵营有ARM架构处理器，主要是高通骁龙X系列芯片，但是目前Windows On Arm（简称WOA）生态仍然不完善，所以本系列不列举WOA笔记本产品及其所搭载的芯片。当然，有些需求用WOA笔记本能够满足的，会在本系列特别篇中列出，希望能对你有所帮助。

无论是X86/64处理器还是Arm处理器，主要由CPU、GPU、NPU和I/O等部分组成，我们在此一一展开介绍。

### CPU

CPU，即 Central Processing Unit（中央处理器），是电脑的最核心部件，用于处理绝大多数指令、调配资源甚至渲染部分2D画面。CPU的优劣，主要看核心数、频率、能效和缓存这几个方面。

#### 核心数

目前的处理器核心主要由P核（即性能核，俗称大核）和E核（即能效核，俗称小核）组成，偶尔还有LPE（即超低功耗能效核，又称超小核）。P核性能更强，可以处理更高负载的任务；E核性能较弱，用来处理低负载任务。以Intel Core Ultra 5-225H处理器为例，这款处理器为4P 8E 2LPE核心，一共14个核心。其中决定单线程高性能的是4P部分，有此需求的同学可以简单理解为4核处理器。

#### 频率

频率，又称时钟速度，决定了一个核心在一秒内能处理的指令数。简单理解，在同代 CPU 之间（核心架构等设计相同），处理器频率越高，性能越强。以Intel Core Ultra5-225H和Ultra 7-255H为例，225H的P核睿频为4.9GHz，255H的P核睿频为5.1GHz，255H的P核比225H的P核性能更强。

#### 能效

能效，决定了 CPU 为了达到特定性能的耗电情况。在性能一定时，能效越高，CPU 功耗越低，对笔记本散热的压力也越小，通常续航也越长。同代 CPU 之间，核心数越多，通常意味着能效越好。目前市面上少有测试笔记本 CPU 能效的测试，一般都是测试满载性能，所以在此不过多赘述。

### GPU

GPU，即 Graphics Processing Unit（图形处理器），也称为显卡，是用于图形渲染、视频处理、AI 训练推理与并行计算的硬件加速器。

在笔记本的电气构造中，根据与处理器的位置关系，GPU 分为**集成显卡**（integrated GPU，iGPU，又称核芯显卡）与**独立显卡**（dedicated GPU，dGPU），前者通常侧重低功耗，用于日常办公娱乐，而后者通常侧重高性能，用于游戏、创意工作与 AI。

目前大多数集显的性能与内存带宽较弱，只有 Apple M Pro/Max/Ultra 系列与其它特殊高端型号，比如 AMD Ryzen AI MAX 系列、Intel Core Ultra X 系列以及 NVIDIA N 系列，拥有高性能、高内存带宽的集显，用来满足部分用户对特定工作的需求。一般情况下，不建议使用集显玩大型游戏（比如黑神话悟空之类），如果有这类需求，建议购买游戏本而非集显本（除了搭载上述处理器的特殊高性能笔记本）。

GPU 的优劣判别与 CPU 相似，除了核心数、频率、能效外，GPU 尤其需要关注其内存容量与带宽。（集成 GPU 的内存就是系统内存，而独立 GPU 的内存与型号绑定。）

#### 核心数

GPU 的核心（计算单元）通常包含各类流式多处理器，比如光追核心、张量核心、CUDA 核心、视频编解码器等。其中最重要的是 ROP（光栅化操作管线），用于处理所有光栅化渲染任务（比如非光追的游戏画面渲染、视频特效渲染、网页渲染、通用的 AI 推理等）。在频率与内存带宽不受限的情况下，GPU 的性能与核心数呈线性关系。

#### 频率

与 CPU 的类似，请参考上文。实践中，笔记本的 GPU 频率由其出厂设置的 TDP（热设计功率）决定，因此可以简单粗暴地理解为，同型号 GPU 功率越高，频率越高，比如 NVIDIA GeForce RTX 5060 laptop 110W 版本的频率上限要比 90W 版本的更高，性能更好。

#### 能效

与 CPU 的类似，请参考上文。同代 GPU之间，核心数越多，通常意味着能效越好。比如 NVIDIA GeForce RTX 50 laptop 系列 GPU，5090 laptop 拥有 112 个 ROP，而 5060 laptop 仅拥有 48 个 ROP，因此 5090 达到 5060 极限性能时，功率仅需后者的一半（受诸多因素影响，并非简单的线性关系），而 175W 时的极限性能可达后者的数倍。

### NPU

NPU，即 Neural Processing Unit（神经处理器），是近十年来在手机平板、近五年来在苹果 MacBook 与近三年来在 Windows 笔记本上逐渐普及的一种处理器，用于加速端侧 AI 的推理，相较于 GPU 可提供低功耗的常驻 AI 功能，如计算摄影、摄像头景深模糊、双向音频降噪、实时字幕、照片视频人物识别与自动分类、屏幕文本识别等。需要注意，虽然微软提出了 Copilot+PC 的概念并大力推广 Windows AI，但 NPU 目前在 Windows 笔记本上实际用处不大：Windows 限制了中国大陆的 AI 功能，且 Windows 生态的大多数第三方应用不会调用 NPU 来加速处理。相较之下，MacBook 自从 M1 处理器开始就集成了与 iPhone A 系列处理器同源的 NPU（苹果称为 Apple Neural Engine，ANE），并在 macOS 本体与其第三方生态中持续发挥作用。

在笔记本的电气构造中，目前可认为只有与处理器集成的 NPU。

因为目前 Windows 笔记本处理器的 NPU 软硬件较混乱且实用价值有限，本文暂不进行具体介绍。

### 缓存

CPU缓存是位于CPU芯片上的高速存储器，用于临时存储CPU可能需要快速访问的数据。它通过减少CPU与主存储器（RAM）之间的交互时间，大幅提升系统性能。现代CPU通常包含三级缓存：L1、L2和L3，每一级缓存在速度、容量和数据命中率之间找到平衡。缓存的预读功能通过预测即将需要的数据，将其提前加载到缓存中，从而进一步减少延迟。现代 CPU 的缓存同样参与 CPU 的指令分支预测功能。

缓存并非越大越好。缓存采用昂贵的静态RAM（SRAM），增加容量会导致晶体管数量和发热量增加，设计复杂性也随之提高。如果设计不合理，可能导致缓存延迟，反而影响性能。因此，缓存大小的选择需根据具体使用场景权衡。例如，视频编辑等任务对缓存的依赖较小，而竞技游戏等任务则能从更大的缓存中获益更多。
