# 华硕 天选7 Pro 酷睿版云评

## 配置

CPU：Intel Core Ultra 7 251HX

GPU：Nvidia GeForce RTX 5060

RAM：16G DDR5 5600MT/s 插槽内存

ROM：512GB/1TB固态硬盘

屏幕：16英寸 2560×1600分辨率 300Hz刷新率 100%DCI-P3色域 500nit亮度 IPS AGLR抗反射雾面屏

电池容量：90Wh

价格：16+512 日蚀灰版本 10999元（国补后9199元）
	      16+1T   魔幻青版本 11999元（国补后10199元）

## 优缺点

### 优点

1. 在一线游戏本中，价格较低
2. 处理器规格较高，单核/多核性能强
3. 屏幕规格极高，且搭载AG抗反射
4. 提供白色选择，颜值较高
5. 高负载下，表面温度控制较好

### 缺点

1. 副盘位与网卡重叠，即所谓的”网卡叠叠乐“，加装硬盘后容易出现硬盘/网卡积热问题
2. 电源为微动设计，寿命较短，且难以维修
3. C面为塑料，手感质感较差
4. 漆面为喷漆工艺，两到三年后可能会出现起皮、脱落现象

## 拓展性

单通道插槽16GB DDR5 5600内存能满足大部分用途的需求，内存为插槽可更换，可以参考配置升级篇进行升级

固态硬盘容量为1TB/512GB，预装在2280规格的M.2插槽上，机器还预留有一个2280规格的M.2插槽，如有需要可以自行加装固态硬盘。

机身左侧接口依次为方形电源接口、RJ45网口、HDMI 2.1 FRL（支持8K60Hz/4K120Hz独显输出）、雷电4（支持DP2.1核显输出）、USB-C 10Gbps（支持DP2.1独显输出和100W PD充电）、USB-A 10Gbps、3.5mm音频接口；
右侧为两个USB-A 10Gbps接口。

## 购买建议

1. 希望购入便宜的一线大厂游戏本
2. 能接受相对较差的用料、品控和售后
3. 对屏幕素质、观感要求较高。

相较于天选6 Pro，天选7 Pro的模具基本没有太多改动，主要升级了处理器和屏幕，并改善了噪音表现。在6月下旬，笔者看京东自营旗舰店里天选7 Pro 酷睿版的价格居高不下，5060版本售价一万多，实在是难以接受；好在7月中旬512版本价格来到了9K价位，这才是符合天选定位的主流价位段，因此笔者将这款笔记本纳入了推荐榜单。

总的来说，天选在一众游戏本中属于是中规中矩，既没有强大的性能释放，也并非极致轻薄，将重量控制在2KG以内，又非质感优秀，属于是还不错，但是缺乏亮点（除了这块屏幕，确实在同价位算是相当不错）。相比之下，笔者还是更推荐天选Air 2025、微星 神影16 2026等同价位的游戏本，当然二次元选天选7 Pro也不太会踩坑，可以放心购入。

## 结语

说实话，笔者其实很不喜欢天选系列笔记本，各种通病实在是夸张，天选6 Pro更新模具后解决了一部分，但是还是有一些遗留问题（比如网卡叠叠乐，又如用久了/暴晒后掉漆）没有解决，天选7 Pro没有选择去更新模具来解决这个问题而是先更新了屏幕进行小改款，这是可以理解的，但是作为长期在校内接电脑维护、维修的“垃圾佬”，笔者还是更希望天选能够再更新一下模具，去解决这些通病问题，这样天选才有对标拯救者的资格。
